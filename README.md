# 👣 Footstep Power Generator ⚡

## 📖 Project Overview

This project generates small electrical energy using footsteps with the help of piezoelectric sensors and Arduino. 
Then the generated voltage and step count are displayed on an I2C LCD display.

## 🛠 Components Used

* Arduino UNO
* Piezoelectric Sensor
* 16x2 I2C LCD
* LED
* Jumper Wires
* Breadboard

## ✨ Features

* 👣 Detects footsteps
* 🔢 Counts steps
* ⚡ Displays generated voltage
* 💡 LED indication for each step

## ⚙️ Working

When pressure is applied on the piezo sensor, it generates voltage. 
Arduino reads this voltage and increases the step count when the voltage crosses a threshold value. 
Then the voltage and step count are shown on the LCD display.

## 🚀 Applications

* 🌱 Smart Energy Generation
* ⚡ Renewable Energy Projects
* 🏢 Smart Flooring Systems
* 📚 Educational IoT Projects

## 📺 Output

* LCD displays step count and voltage
* LED blinks when a step is detected
